# 붙임2 AI 모델 활용 및 라이선스 기술 명세서

> 제출용 원문. 2026 오픈소스 개발자대회 결과보고서 붙임2 서식에 그대로 옮겨 적는다.
> 근거 규정 = 대회 운영규정 제9조(AI 모델 활용의 기준) · [별표2] AI 모델 활용 가이드 · 공식 QnA(2026-07-28).

## 1. AI 모델 활용 유형

- ▣ **유형 1: 외부 모델 그대로 활용** (추가 학습 없이 기존 공개 모델을 프로젝트에 연동·구동)
- □ 유형 2: 외부 모델 파인튜닝
- □ 유형 3: 자체 개발 모델

가중치를 새로 학습하거나 미세조정한 사실이 없다. 공개된 오픈웨이트 모델을 **로컬 Ollama 런타임으로 직접 구동**하여 MCP 도구 체인에 연결했다.

## 2. 기반(베이스) 모델 정보

| 모델 | 역할 | 기반 모델명 및 개발사 | 라이선스 | 공개 수준 | 구동 방식 |
| --- | --- | --- | --- | --- | --- |
| 생성 LLM | 질의 의도 분해, NL2SQL, 근거 기반 한국어 답변 생성 | **Qwen2.5-7B-Instruct** (Alibaba Cloud) | **Apache-2.0** | 오픈웨이트(가중치 공개) | Ollama `qwen2.5:7b`, Q4_K_M, 7.6B params, context 32768, `temperature 0 / seed 42 / num_ctx 4096` 고정 |
| 임베딩 | 문서·질의 임베딩(1024차원), 벡터 검색 | **BGE-M3** (BAAI) | **MIT** | 오픈웨이트(가중치 공개) | Ollama `bge-m3`, 8192 토큰 컨텍스트, dense 1024-dim (`documents.embedding vector(1024)`와 일치) |

- 두 모델 모두 운영규정 제9조①의 **"최소 오픈웨이트 이상"** 요건을 충족한다.
- 공식 QnA(2026-07-28)가 **임베딩 모델도 제9조 적용 대상**임을 명시했고, BGE는 사용 가능 예시로 적시됐다.
- 별표2의 **'독립 구동 가능성'** 요건: 두 모델 모두 로컬 Ollama에서 직접 구동되며, **상용 API 전용 모델을 서비스로 연결한 부분이 없다**. 코드 전체에 외부 모델 API 호출 경로가 존재하지 않는다(`OPENAI_*`, `ANTHROPIC_*` 등 키 참조 0건).
- 지정과제(리원에이스) 요구사항인 **"LLM은 Ollama 로컬 실행, 외부 API 사용 불가"**와 동일 조건이다.
- 결정론 보조 경로로 **HashEmbedder**(자체 구현 feature-hashing)를 오프라인 CI 폴백으로 둔다. 외부 모델이 아니라 프로젝트 자체 코드이며, 의미 검색 성능은 BGE-M3 대비 낮음을 실측으로 공개한다(hit@5 1.00 vs 0.75).

## 3. 데이터셋 정보 및 가중치 배포 명세

**해당 없음** (유형 1). 추가 학습을 수행하지 않았으므로 새로 생성된 가중치가 없다.

- 평가·시연에 사용한 데이터는 리원에이스가 배포한 지정과제 공식 데이터셋 `companyx-dataset-v1.0`이다. 배포 라이선스가 대회 목적 사용으로 한정되어 **저장소에 재배포하지 않고**, 취득 스크립트(`scripts/fetch-companyx-dataset.sh`)와 SHA-256 명세(`datasets/MANIFEST.md`)로 재현 가능하게 했다.
- 그 외 벤치마크는 결정론적으로 생성되는 자체 합성 코퍼스(`gen:bench`, seed 42)와 외부 공개 벤치마크(BIRD Mini-Dev)를 사용했다.
